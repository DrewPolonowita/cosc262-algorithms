# COSC262 Algorithms
A place to store my algorithms written in preparation for the COSC262 exam. The
types of algorithms include graph traversal algorithms such as DFS, BFS and Dijkstra's.
Algorithms on vectors and points such as closest-pair, range search and graham scans.
Then dynamic algorithms such as the knapsack problem and greedy algorithms like huffman encoding

## Note
This project is not designed to be used separately. But to be pulled and used as an internal API
